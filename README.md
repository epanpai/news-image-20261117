Sums up the world's news of Tuesday 17 November 2026 in one image — a newspaper
front page drawn for the day: Ukraine strikes the Kerch Bridge again, tankers
hit by mines off Hormuz, Trump lands in Manila ahead of the Xi–Trump–Putin
summit, and the Vulcan rocket failure that destroyed 40 Amazon satellites,
plus the day's other briefs.

`main.py` (Python 3.13, standard library only) copies the finished front page
(`assets/entry.png`, drawn by `gen_image.py`) to `/output/entry.png`. No
network, no randomness — two runs write byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
